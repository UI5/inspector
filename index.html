Main Features

Control Inspector

Browse a live control tree and select any element to inspect it. View and edit properties on the fly, and inspect bindings, aggregations, slots, and events. Filter the tree by search term, toggle namespaces and attributes, and hover any row to highlight the matching element on the page — or right-click an element and choose "Inspect UI5 element" to jump straight to it.

Application Information

See the framework name and version, loaded libraries, and bootstrap configuration for your app. For UI5 Web Components apps, view the detected runtimes, OpenUI5 interop status, and the registered component tags in use on the page.

OData Requests

Monitor your app's OData calls directly in the DevTools panel. Sort requests by name, method, or status, and inspect the response body with syntax highlighting.

Elements Registry

Browse every registered UI5 control in the app — including ones not currently rendered on screen. Search and filter by control type or ID, hover to highlight on the page, and drill into the XML view and controller bound to each view.

AI Assistant

Ask plain-language questions about the selected control or web component. The assistant automatically sees its properties, bindings, events, and slots — plus console errors from the inspected page — so there's no copy-pasting. Powered by Chrome's built-in on-device AI (Gemini Nano): no API key, no external service, and no data leaves your device.
